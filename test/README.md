# Test builds

Performance test builds, one folder per version. Not the live game (that's `index.html` at the root).
Open a build with `?autotest` for the hands-free device test, e.g. `test/v1/?autotest`.

- `test/v5.0.4/`: v5.0.4 polish test (playtest fixes from branch `v5.0.3-playtest-fixes`). Scores post to the live boards as version v5.0.4.
